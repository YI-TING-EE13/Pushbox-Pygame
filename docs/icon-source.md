# Icon Resource and Licensing Record

This document records the creation process, design specs, and licensing compliance for the Pushbox-Pygame application icon.

## 1. Creation Details
- **Creation Date**: 2026-05-27
- **Creation Tool**: Custom Python Pygame drawing script (`scripts/generate_icon.py`)
- **Author/Creator**: Pushbox-Pygame Project Maintainer

## 2. Design Specifications
- **Design Option**: Option C — Nord geometric bear pushing a crate
- **Design Description**: 
  - Fuses the cute geometric bear mascot (retaining player identity from the in-game procedural fallback) with the Sokoban crate (maintaining strong gameplay recognition).
  - Designed in compliance with the dark theme aesthetic using the Nord color palette:
    - Background: Nord Dark Blue-Grey `(40, 44, 52)`
    - Bear Head: Soft Purple `(198, 120, 221)` and Shadow `(158, 80, 181)`
    - Bear Eyes: Dark Grey `(40, 40, 40)`
    - Bear Cheeks: Blush Pink `(255, 180, 200)`
    - Crate: Soft Yellow/Gold `(229, 192, 123)` with Outline `(100, 80, 40)`
  - No text, no gradients, no complex backgrounds, no unverified web assets.

## 3. Multi-resolution ICO Layers
To prevent small icon resolution scaling from blurring, the script employs discrete design simplification at smaller sizes:
- **256x256**: High detail. Full geometric小熊 (ears, eyes, blush) and Sokoban wooden crate with detailed outline and cross lines.
- **48x48**: Medium detail. Simplified bear head and crate with proportional coordinates.
- **32x32**: High contrast. Head with simple dots for eyes and ears, crate with simple outline.
- **16x16**: Pixel-level simplicity. High-contrast 3px radius bear head and 6x6 crate to prevent detail muddying on Windows desktop.

## 4. Generation & Drawing Steps
1. The script initializes Pygame in a headless memory canvas.
2. Draws transparent background surfaces for sizes `16, 32, 48, 256`.
3. Renders a rounded dark Nord card background for each canvas.
4. Renders pixel-aligned shapes representing the bear and crate composition for each size.
5. Saves each canvas to a temporary `.png` file.
6. Combines the bytes of the 4 generated PNGs into a compliant standard multi-resolution `.ico` file using Python `struct`.
7. Clears temporary folders, outputting a lightweight `.ico` file.
